# AI Conversation Logs

This directory contains preserved AI conversation logs for the StoneAI project.
These logs capture important discussions, architectural decisions, and debugging steps made during the development process.

## Structure

Logs are named using the following format:
`ai-log-YYYY-MM-DD-session-name.md`

## Content Guidelines

Logs typically include:
- Feature discussions
- UI/UX planning
- Debugging steps
- Architecture decisions
- Generated prompts
- Deployment/setup discussions

**Important:** Never delete previous logs. Always ensure logs are committed to git before pushing code.
